People
suraj is the policy owner: policy paths, stable promotion and repo settings. Approvals are advisory today: qq-main requires 0, code-owner review is enforced only on toolchains, and gate.toml's change classes wait on V0-GAT-03.
org.toml names suraj owner of the org and all 13 infra repos (infra-config 310e326). Other config areas and the product repos in repos.toml still have empty owners lists (V0-ORG-02).
Every infra repo's CODEOWNERS names suraj on its policy and trust paths, with no catch-all.

Agents and bots
Policy allows agents to land clean reverts, dependency rolls and docs alone. In v0 none of these land on their own (auto_land_repos is empty and roll auto-land is off). Canary promotion is the one thing agents do alone today.
One GitHub App per tool. Exists: quirqer (rollers). Not yet created: the gardener App (needed before exit test 4 can pass) and the release executor (product-repo refs and, later, depot release tags).
GitHub does not let a PR's author approve it: suraj can approve agent PRs (opened as quirq-gates), but suraj's own PRs need a second owner or a bot.
