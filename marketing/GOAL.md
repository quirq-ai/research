# Goal: marketing

## Purpose

quirq has no Reddit presence yet. Before posting anything, we want to know
where agent builders on Reddit are asking questions that quirq's own data can
answer, what they are asking, and what the existing replies already cover, so
that anything we post adds something new instead of repeating it. The answer
informs Yash's Reddit and community plan.

## Research questions

1. In r/AI_Agents, r/AgentsOfAI, r/LLMDevs and r/ClaudeAI, which recent
   threads ask about agent cost and token bills, choosing models for coding
   agents, model routing, agent memory across sessions, running several agents
   or harnesses (Claude Code, Codex) together, or evaluating agent output?
2. What do the posters actually ask, and what do the existing replies already
   say?
3. Which questions are still open, where a builder with real data could help?
4. How quickly do these subreddits move, and can their public data be read
   without logging in?

## Research action

- Read each subreddit's newest 100 and rising 25 posts from Reddit's public
  feeds, without logging in, posting, voting or commenting.
- Keep posts from the last 72 hours on the topics above; drop link-only
  promotion and "best framework?" polls.
- Shortlist open questions with fewer than about 60 comments.
- Read the full post and the first ten top-sorted comments of the ten best
  threads, and group what the replies already cover.

## Scope

**In scope:**

- Public posts and comments in the four subreddits, 10 to 13 October 2026.

**Out of scope:**

- Posting, commenting, voting or creating accounts.
- Reddit usernames or any other personal data. Threads are cited by link only.
- Other subreddits and other platforms.

## Done when

- A report lists the shortlisted threads with links, what each one asks, what
  the replies cover and what is still open, plus the method and its limits.
