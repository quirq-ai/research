# onepager

A single-page summary of the verified findings, readable in a couple of
minutes.

Include: the question, the short answer, three to five key findings, and the
sources. Markdown (`.md`) or PDF, and it must fit on one page.

Name files `YYYY-MM-DD-<short-name>.<ext>`. Publish here only if "onepager" is
ticked under "Requested outputs" in `GOAL.md`.
