# slide

A slide deck for presenting the verified findings.

Commit the deck (`.pptx`, PDF, or Markdown slides) and, if it is generated
from a source file, that source too. Put sources on a final slide or in the
speaker notes.

Name files `YYYY-MM-DD-<short-name>.<ext>`. Publish here only if "slide" is
ticked under "Requested outputs" in `GOAL.md`.
