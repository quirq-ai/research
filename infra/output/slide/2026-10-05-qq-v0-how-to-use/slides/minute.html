WHAT QQ IS
One config repo decides; small tools apply it
Modelled on Chromium. infra-config declares every repo, builder, gate rule and channel as TOML. The tools that apply policy read it at a pinned commit.
Repo-agnostic. Core tools never name a language or product; a product repo writes one manifest and gets the rest generated.
Agents first. Policy allows agents to land clean reverts, dependency rolls and docs alone. In v0 none of these land on their own (auto_land_repos is empty and roll auto-land is off). Canary promotion is the one thing agents do alone today.
Public, GitHub-hosted. 13 infra repos, all Apache-2.0, serving two product repos: xo-space and innernet.
