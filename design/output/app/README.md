# app

A runnable demo that shows the findings in action.

Put each app in its own folder, `output/app/<app-name>/`, with a README that
gives:

- what the demo shows and which finding it supports
- requirements (language, runtime, versions)
- setup steps
- the exact command to run it
- what you should see when it works

Pin dependency versions. Do not commit secrets or API keys; read them from
environment variables and name those variables in the README.

Publish here only if "app" is ticked under "Requested outputs" in `GOAL.md`.
