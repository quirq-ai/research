From a verdict to a channel
qq try returns a run ID at once and delivers the verdict later to $QQ_HOME/verdicts/, so an agent never holds a call open.
qq status gives it on demand: exit 0 pass, 1 refused, 3 pending.
qq land queues the PR once the gate passes; the merge queue re-tests the exact merge result and squash-merges.
After it lands, the post-submit builder runs on every main commit and gardener checks the tree every 5 minutes, proposing a revert if main goes red.
Dependencies move by Dependabot PRs, checked by qq-roll-land, and toolchain roll PRs from quirqer. A person merges every roll in v0.
Ship. release moves lkgr to the newest all-green main commit; the daily canary at 06:17 UTC builds, tests, deploys and probes it before moving channels/canary.
qqinstall resolve --repo xo-space --channel canary gives the commit and digest to install; exit 3 until the first canary ships.
Measure. perf records build size and a benchmark per main commit.
