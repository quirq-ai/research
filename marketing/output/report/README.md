# report

A long-form write-up of the research.

Cover: the question and context, the method, the findings with evidence,
limitations and open questions, and a full list of references. Markdown
(`.md`) or PDF.

Name files `YYYY-MM-DD-<short-name>.<ext>`. Publish here only if "report" is
ticked under "Requested outputs" in `GOAL.md`.
