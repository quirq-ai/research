HOW TO USE IT · 1 OF 2
From a fresh clone to an open PR
1
Set up once
Clone depot and put its bin on PATH. In a product repo, qq runs the version pinned in infra/repo.toml (both pin 0.1.0, depot main).
2
Get toolchains: qq sync
Fetches every pinned toolchain from public ghcr, checks its digest, links it under .qq/toolchains/. Runs daily for both repos.
3
Build and test: qq build, qq test
Recipes run the targets and leave JUnit and results.json in .qq/out.
4
Open a PR: qq upload or a plain push
The <repo>-presubmit check runs a drift check, then fetch, build and test, then stores every result in test-pipelines.
